# Elmajiku Radius

An ISP hotspot and bandwidth-billing system project concept.

## Project scope

The portfolio describes subscriber billing workflows, MikroTik RouterOS integration, and WhatsApp notifications.

## Technologies listed in the portfolio

- PHP 8 and MySQL
- MikroTik RouterOS API
- WhatsApp bot integration

## Status

This repository currently contains project documentation only. Source code, router credentials/configuration, integration tests, and live ISP deployment evidence are not included.
